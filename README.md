# Application de vente de formation.

Dans un premier temps, l'application doit permettre à tous les utilisateurs non connectés d'afficher toutes les formations disponibles, d'afficher toutes les formations contenant un mot clé, toutes les formations en présentiel ou distanciel.`

Dans un second temps, l'application permet de constituer un panier en ajoutant/retirant des formations avec possibilité de passer commande à tout instant, à condition d'être connecté, sinon il sera orienté vers la création d'un utilisateur (login + password), une commande devra être associée à un client (nom, prénom, email, adresse, tel), un utilisateur peut réaliser plusieurs commandes pour différents clients.
